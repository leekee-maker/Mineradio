# SelfRadio 交互审计

审计范围：播放页与首页。目标是降低找歌、播放、切换页面和调整设置的学习成本。

## 步骤

1. 播放页（需优化）：沉浸视觉突出，但主要导航和播放控制依赖悬浮、自动隐藏与图标记忆。
2. 首页（需优化）：信息丰富，但首页、视觉舞台、设置、队列同时存在，入口分散且层级不稳定。

## 主要问题

- 缺少稳定的全局导航；Home、搜索、账号、视觉设置分散在不同位置。
- 底部播放器一次展示过多图标，常用与低频操作没有分层。
- “DIY”“视觉控制台”“全沉浸式”等概念偏开发者语言，新用户难以预测结果。
- 首页卡片较多，但“继续播放、音乐库、每日推荐、最近播放”的优先级接近。
- 自动隐藏面板和悬浮按钮增强沉浸感，也增加了找入口的成本。
- 小尺寸灰色文字、纯图标按钮和动态背景存在对比度、可识别性与键盘焦点风险。

## 优先建议

1. 增加稳定导航：主页、搜索、音乐库、平台、设置。
2. 底栏只保留歌曲信息、上一首、播放、下一首、音量、队列、全屏；其余收入“更多”。
3. 默认进入首页，主动点击“进入舞台”后才切换沉浸播放。
4. 把“DIY”改为“视觉模式”，将视觉控制台设为二级功能。
5. 统一账号中心：集中显示网易云、QQ、汽水登录状态及退出入口。
6. 提供“简洁模式 / 沉浸模式”两个明确预设，不要求用户理解大量视觉参数。

## 适合增加的功能

- 本地音乐文件夹自动扫描与变化监听。
- macOS 媒体中心、Windows 系统媒体控制和全局快捷键。
- 迷你播放器、菜单栏控制、睡眠定时。
- 歌单导入导出（M3U/JSON）与本地备份。
- ReplayGain、均衡器预设、无缝播放与交叉淡入淡出。
- 平台适配器接口，将音乐源与播放器 UI 解耦。

## 证据限制

本次依据当前桌面画面与可访问性结构审计；未完整验证键盘遍历、屏幕阅读器、缩放和所有登录异常状态。
